# Research software engineering for you

:::{admonition} Preparation
- Get a GitHub account ([instructions](https://coderefinery.github.io/installation/github/))
- To work on your own computer instead of the GitHub webinterface: [get and configure git](https://coderefinery.github.io/installation/git-in-terminal/), [choose and configure an editor](https://coderefinery.github.io/installation/editors/) and [set up ssh connection](https://coderefinery.github.io/installation/ssh/).
- [Install Sphinx with conda or pip](https://coderefinery.github.io/installation/conda/), this environment includes some other useful tools as well.

Please note that these links are part of a larger installation guide for a full CodeRefinery workshop, so there might be mention of days or weeks or general workshop setup things that do not apply to us. Do not hesitate to ask if something is unclear. 

In the end, you should have the following ready: 
- Git installed on your computer and know where/how to use it (e.g. Terminal, git bash, Anaconda prompt, ...)
- GitHub account
- Sphinx installed on your computer and know where/how to use it (e.g. `conda activate` )

:::

:::{admonition} Choose your own adventure
Each episode has exercises or something to think about.  There are too many
exercises to complete during the workshop. Please start with the ones that are **most
relevant to you and your work** and try to complete one or two. If you
have time, you can continue with the remaining exercises. If you have the
possibility to work in pairs, please do so.
